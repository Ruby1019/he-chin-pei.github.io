# Chin-Pei He Academic Portfolio

This repository contains a static GitHub Pages academic portfolio for Chin-Pei He.

## Contents

- `index.html` - main academic profile website
- `styles.css` - responsive page styling
- `files/He_Chin_Pei_CV.pdf` - general CV
- `files/He_Chin_Pei_Academic_CV.pdf` - academic CV
- `.github/workflows/pages.yml` - GitHub Pages deployment workflow

## Deployment

Push this repository to GitHub with the default branch named `main`.
The included GitHub Actions workflow deploys the site to GitHub Pages.

The enrollment certificate and autobiography were used only as source material
for summarizing the academic profile. They are not included as public downloads.
