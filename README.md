# Chin-Pei He Academic Portfolio

This repository contains a static GitHub Pages academic portfolio for Chin-Pei He.

## Contents

- `index.html` - main academic profile website
- `styles.css` - responsive page styling
- `assets/profile-web.jpg` - profile photo

## Deployment

Deploy from the `main` branch root directory in GitHub Pages settings.

The CVs, enrollment certificate, and autobiography were used only as source
material for summarizing the academic profile. They are not included as public
downloads.
